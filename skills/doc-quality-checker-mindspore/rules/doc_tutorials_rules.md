# 教程/文档检查规则

## 文本层面

| 编号 | 要求 |
|------|------|
| T-T-01 | 文件名使用全小写，单词间可使用_分隔。 |
| T-T-02 | 每篇教程/文档都有查看源文件的链接，其中Jupyter Notebook还需包含“下载Notebook”和“下载样例代码”的链接（全文没有代码或英文文档，可以除外） |
| T-T-03 | 求梯度或导数的描述需准确 |
| T-T-04 | 中英文内容需完全保持一致，昇腾社区只有中文，英文可不体现 |

## 样例代码层面

| 编号 | 要求 |
|------|------|
| T-C-03 | 样例代码可完整运行 |
| T-C-04 | 样例代码运行结果无ERROR/WARNING |
| T-C-05 | 样例代码中不使用已标记弃用的API |
| T-C-06 | 如果文中给出了样例代码链接，该样例代码与本文描述保持一致 |
| T-C-07 | Jupyter Notebook文件无stderr或stdwarn，stdout中无Error或Warning信息 |
