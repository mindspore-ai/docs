# C++ API英文注释检查规则

**说明**：本文件包含C++ API英文注释的检查规则，对应中文MD文档。

## 必须的注释项

| 编号 | 注释项 | 格式 | 要求 |
|-----|-------|------|------|
| I-CP-R-01 | \brief | `/// \brief 简要描述` | 必须有 |
| I-CP-R-02 | 详细描述 | 多行 `///` 描述 | 根据需要 |
| I-CP-R-03 | \note | `/// \note 注意事项` | 根据需要 |
| I-CP-R-04 | \param[in] | `/// \param[in] name 说明` | 参数必须有 |
| I-CP-R-05 | \return | `/// \return 返回值说明` | 必须有 |
| I-CP-R-06 | \par Example | `/// \par Example` + code block | 根据需要 |

## 格式检查

| 编号 | 检查项 | 正确格式 | 错误示例 |
|-----|-------|---------|---------|
| I-CP-F-01 | 注释前缀 | 统一使用 `///` | 使用 `//` |
| I-CP-F-02 | 空行处理 | 使用 `///` 保持空行 | 直接空行 |
| I-CP-F-03 | 参数格式 | `\param[in] name 说明` | 格式错误 |
| I-CP-F-04 | 返回值格式 | `\return 说明` | 格式错误 |

## 公式检查

| 编号 | 检查项 | 正确格式 | 错误示例 |
|-----|-------|---------|---------|
| I-CP-M-01 | 多行公式 | `\f[ ... \f]` | 格式错误 |
| I-CP-M-02 | 行内公式 | `\f$ formula \f$` | 格式错误 |

## 引用检查

| 编号 | 检查项 | 正确格式 | 错误示例 |
|-----|-------|---------|---------|
| I-CP-RF-01 | 外部引用 | `@ref class_name` | 直接写名称 |
| I-CP-RF-02 | 避免错误链接 | 前面加 `@ref` | 格式错误 |

## 示例代码检查

| 编号 | 检查项 | 正确格式 | 错误示例 |
|-----|-------|---------|---------|
| I-CP-E-01 | Example标签 | `\par Example` | 格式错误 |
| I-CP-E-02 | code块 | `\code` + 内容 + `\endcode` | 格式错误 |
| I-CP-E-03 | 缩进 | 代码内容正常缩进 | 缩进错误 |

## 常见错误汇总

### C++注释错误

1. 使用 `//` 而非 `///`
2. 空行处直接空行而非使用 `///`
3. 参数说明格式错误
4. 公式格式错误
5. 引用未加 `@ref`

### 完整性错误

1. 缺失必需的注释项（\brief/\param/\return）
2. 参数说明不完整
3. 返回值说明缺失
4. 示例代码不可运行

---

## 格式验证要点

### 注释前缀

- 统一使用 `///` 而非 `//`
- 空行处使用 `///` 保持连续

### 空格和缩进

- 参数名和方向标记 `[in]` 之间有空格
- 不同类型内容间有空行
- 代码块内容正常缩进

### 标签格式

- `\brief`、`\param`、`\return` 等标签使用反斜杠开头
- 外部引用使用 `@ref` 前缀
