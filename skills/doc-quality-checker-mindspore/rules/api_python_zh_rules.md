# Python API中文文档检查规则

**说明**：本文件包含Python API中文文档（RST格式）的检查规则，对应 `.py` 英文源码或 `.yaml` / `.yml` 配置文件。

## 类（Class）检查项

| 编号 | 检查项 | 正确格式 | 错误示例 |
|-----|-------|---------|---------|
| I-C-01 | 类定义格式 | `.. py:class:: mindspore.Tensor(default_input, dtype=None, ...)` | 缺少 `.. py:class::` 前缀 |
| I-C-02 | 参数顺序 | 与API定义中的参数顺序一致 | 参数顺序与定义不一致 |
| I-C-03 | 可选参数标注 | 参数后加 `(类型, 可选)` | 未标注可选 |
| I-C-04 | 默认值说明 | 参数后说明 `默认值： ``xxx`` 。` | 未说明默认值 |
| I-C-05 | 二级参数缩进 | 二级参数与一级参数的 `*` 对齐 | 缩进不一致 |
| I-C-06 | 返回值说明 | 在 `返回：` 后说明 | 缺失返回值说明 |
| I-C-07 | 输入/输出说明 | 在 `输入：` 和 `输出：` 下详细说明 | 缺失输入/输出说明 |
| I-C-08 | 异常说明 | 在 `异常：` 下分类列出 | 异常混乱或缺失 |

## 方法（Method）检查项

| 编号 | 检查项 | 正确格式 | 错误示例 |
|-----|-------|---------|---------|
| I-M-01 | 方法缩进 | 相对于类增加4空格缩进 | 缩进错误 |
| I-M-02 | 静态方法标签 | `:staticmethod:` | 缺少标签 |
| I-M-03 | 抽象方法标签 | `:abstractmethod:` | 缺少标签 |
| I-M-04 | 类方法标签 | `:classmethod:` | 缺少标签 |
| I-M-05 | 特殊方法引用 | 使用 `` :func:`xxx` `` 引用 | 直接写接口名 |

## 函数（Function）检查项

| 编号 | 检查项 | 正确格式 | 错误示例 |
|-----|-------|---------|---------|
| I-F-01 | 函数定义 | `.. py:function:: name(参数)` | 格式错误 |
| I-F-02 | 有重载函数 | 使用 `.. py:function::` + `:noindex:` | 缺失重载标记 |
| I-F-03 | 参数说明 | 参数类型在数据类型后说明 | 参数说明不完整 |
| I-F-04 | 返回值说明 | 在 `返回：` 下详细说明 | 缺失返回值 |

## 样例格式检查

| 编号 | 检查项 | 正确格式 | 错误示例 |
|-----|-------|---------|---------|
| I-S-01 | Note样式 | `.. note::` + 缩进四格 | 格式不正确 |
| I-S-02 | Warning样式 | `.. warning::` + 缩进四格 | 格式不正确 |
| I-S-03 | See also样式 | `.. seealso::` + 缩进四格 | 格式不正确 |
| I-S-04 | 教程样例 | 在 `教程样例：` 下添加链接 | 格式错误 |
| I-S-05 | 样例中Note | 在 `样例：` 下加 `.. note::` | 位置错误 |
| I-S-06 | code-block样式 | `.. code-block::` 后空一行再接代码 | `.. code-block::` 后直接接代码内容，导致指令解析失败 |

## 链接格式检查

| 编号 | 检查项 | 正确格式 | 错误示例 |
|-----|-------|---------|---------|
| I-L-01 | 链接文本格式 | ``链接文本 <超链接URL>`_`` | 缺少空格 |
| I-L-02 | 链接前后空格 | 链接文本前后有空格 | 紧贴其他文字 |
| I-L-03 | 引用格式 | `` :class:`类全称` `` | 引用格式错误 |

## 特殊字符检查

| 编号 | 检查项 | 正确写法 | 显示效果 |
|-----|-------|---------|---------|
| I-E-01 | 星号强调 | `\*text\*` | *text*（斜体） |
| I-E-02 | 双星号加粗 | `\*\*text\*\*` | **text**（加粗） |
| I-E-03 | 反引号代码 | ````text```` | ``text`` |
| I-E-04 | 不嵌套标记 | 不能互相嵌套 | 错误嵌套 |
| I-E-05 | 空格要求 | 标记前后有空格 | 缺少空格 |

## 内容注意事项

| 编号 | 检查项 | 要求 |
|-----|-------|------|
| I-N-01 | 参数顺序 | 需与API定义中的参数顺序保持一致 |
| I-N-02 | 可选参数 | 需在参数数据类型后面增加"可选"字样 |
| I-N-03 | 关键字参数 | `*` 之后的参数单独写至"关键字参数"模块 |
| I-N-04 | 同类异常 | 将同类异常放在一起 |
| I-N-05 | 维度描述 | 使用文字方式（零维、一维、二维等） |
| I-N-06 | 专有名词 | 保持英文原词（NumPy、Python、MindSpore等） |
| I-N-07 | 返回值内容 | `返回：`部分的内容中不能包含冒号（:），需使用逗号替代 |
| I-N-08 | 描述内容 | 类/方法/函数描述中不能包含冒号（:） |

## 不需要的内容

- 不需要手写"支持平台"
- **不需要手写"样例"（中文RST不包含示例）**
- 不需要手写"Supported Platforms"（会自动生成）

## 常见错误汇总

### Python API（RST）错误

1. 类定义缺少 `.. py:class::` 前缀
2. 参数顺序与API定义不一致
3. 缺少可选参数标注（未加"可选"）
4. 返回值说明缺失
5. 异常说明格式混乱
6. 方法缩进不正确
7. 特殊字符（`*`、`:`）未转义
8. 链接格式缺少空格
9. 描述内容中包含冒号

### 完整性错误

1. 缺失必需的输入/输出说明
2. 参数说明不完整
3. 异常说明缺失
4. 关键字参数未单独模块

## 格式验证要点

### 空格和缩进

- 类/方法缩进：方法相对于类增加4空格
- 二级参数缩进：与一级参数的 `*` 对齐
- 链接前后有空格

### 冒号使用

- 关键字后有冒号（如 `返回：`、`异常：`）
- 描述内容中不能包含冒号
- 返回值内容中不能包含冒号，需使用逗号替代

### 列表格式

- 同类型列表项间无空行
- 无序/有序列表内容与上方内容间有空行
- 二级列表正确缩进
