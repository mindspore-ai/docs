# C++ API中文文档检查规则

**说明**：本文件包含C++ API中文文档（MD格式）的检查规则，对应 `.h/.cpp` 英文源码。

## 文件命名检查

| 编号 | 类型 | 正确命名 | 错误示例 |
|-----|-----|---------|---------|
| I-CPP-F-01 | class | `class{namespace}_{classname}.md` | 格式不匹配 |
| I-CPP-F-02 | struct | `struct{namespace}_{structname}.md` | 格式不匹配 |
| I-CPP-F-03 | enum | `enum_{namespace}_{enumname}-1.md` | 序号缺失 |
| I-CPP-F-04 | function | `function_{namespace}_{functionname}-1.md` | 序号缺失 |
| I-CPP-F-05 | typedef | `typedef_{namespace}_{typedefname}-1.md` | 序号缺失 |

## 内容格式检查

| 编号 | 检查项 | 正确格式 | 错误示例 |
|-----|-------|---------|---------|
| I-CPP-C-01 | 头文件引用 | 在开头给出 `#include &lt;[xxx.h](url)&gt;` | 缺失头文件 |
| I-CPP-C-02 | 构造函数 | 单独写在不同代码块 | 与其他合并 |
| I-CPP-C-03 | 析构函数 | 单独写在不同代码块 | 与其他合并 |
| I-CPP-C-04 | 接口顺序 | 与头文件声明顺序一致 | 顺序不一致 |
| I-CPP-C-05 | 参数说明 | 使用 `- 参数名: 说明` 格式 | 格式错误 |
| I-CPP-C-06 | 返回值说明 | 说明状态码和使用方法 | 说明不完整 |

## Markdown格式检查

| 编号 | 检查项 | 要求 |
|-----|-------|------|
| I-CPP-M-01 | 标题层级 | 使用 `#`, `##`, `###` 正确层级 |
| I-CPP-M-02 | 代码块 | 使用 ```cpp 包裹代码 |
| I-CPP-M-03 | 表格 | 正确使用 markdown 表格 |
| I-CPP-M-04 | 链接 | 使用 `[text](url)` 格式 |

## 常见错误汇总

### C++ API（MD）错误

1. 文件命名不符合规范（未使用 `{type}_{namespace}_{name}.md`）
2. 头文件引用缺失
3. 构造函数/析构函数未单独写代码块
4. 接口顺序与头文件声明不一致
5. 参数说明格式错误（未使用 `- 参数名: 说明`）
6. Markdown标题层级错误
7. 代码块未使用 ```cpp
8. 表格格式不正确

### 完整性错误

1. 缺失必需的输入/输出说明
2. 参数说明不完整
3. 异常说明缺失

## 格式验证要点

### 代码块

- 代码块使用 ```cpp 包裹
- 构造函数/析构函数使用独立代码块

### 列表格式

- 同类型列表项间无空行
- 无序/有序列表内容与上方内容间有空行
- 二级列表正确缩进

### 链接引用

- 使用 `[text](url)` 格式
- 头文件引用包含超链接
