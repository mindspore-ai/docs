# mindspore.ops API Interface Change

Compared with the version 2.7.2, the added, deleted and supported platforms change information of `mindspore.ops` operators in version 2.8.0, is shown in the following table.

|API|Status|Description|Support Platform|Class
|:----|:----|:----|:----|:----
[mindspore.ops.nsa_compress](https://mindspore.cn/docs/en/r2.8.0/api_python/ops/mindspore.ops.nsa_compress.html#mindspore.ops.nsa_compress)|New|Compress the KV sequence dimension using the NSA Compress algorithm to reduce attention computation in long-context training.|r2.8.0: Ascend|Array Operation
[mindspore.ops.nsa_compress_attention](https://mindspore.cn/docs/en/r2.8.0/api_python/ops/mindspore.ops.nsa_compress_attention.html#mindspore.ops.nsa_compress_attention)|New|Use NSA Compress Attention algorithm for attention compression computation (Ascend).|r2.8.0: Ascend|Array Operation
[mindspore.ops.sparse_segment_mean](https://mindspore.cn/docs/en/r2.8.0/api_python/ops/mindspore.ops.sparse_segment_mean.html#mindspore.ops.sparse_segment_mean)|Changed|r2.7.2: Computes the mean of sparse segments in the input tensor. => r2.8.0: ops.sparse_segment_mean is deprecated from version 2.8.0 and will be removed in a future version.|r2.7.2: GPU/CPU => r2.8.0: Deprecated|Array Operation
[mindspore.ops.approximate_equal](https://mindspore.cn/docs/en/r2.8.0/api_python/ops/mindspore.ops.approximate_equal.html#mindspore.ops.approximate_equal)|Changed|r2.7.2: Return a boolean tensor where two tensors are element-wise equal within a tolerance. => r2.8.0: ops.approximate_equal is deprecated from version 2.8.0 and will be removed in a future version, please use mindspore.Tensor.isclose() instead.|r2.7.2: Ascend/GPU/CPU => r2.8.0: Deprecated|Comparison Functions
[mindspore.ops.accumulate_n](https://mindspore.cn/docs/en/r2.8.0/api_python/ops/mindspore.ops.accumulate_n.html#mindspore.ops.accumulate_n)|Changed|r2.7.2: Return the element-wise sum of all input tensors. => r2.8.0: ops.accumulate_n is deprecated from version 2.8.0 and will be removed in a future version, please use mindspore.ops.addn() instead.|r2.7.2: Ascend/GPU => r2.8.0: Deprecated|Element-wise Operations
[mindspore.ops.padding](https://mindspore.cn/docs/en/r2.8.0/api_python/ops/mindspore.ops.padding.html#mindspore.ops.padding)|Changed|r2.7.2: Extends the last dimension of the input tensor from 1 to pad_dim_size, by filling with 0. => r2.8.0: ops.padding is deprecated from version 2.8.0 and will be removed in a future version, please use mindspore.ops.pad() instead.|r2.7.2: Ascend/GPU/CPU => r2.8.0: Deprecated|Image Functions
[mindspore.ops.batch_dot](https://mindspore.cn/docs/en/r2.8.0/api_python/ops/mindspore.ops.batch_dot.html#mindspore.ops.batch_dot)|Changed|r2.7.2: Computation of batch dot product between samples in two tensors containing batch dims. => r2.8.0: ops.batch_dot is deprecated from version 2.8.0 and will be removed in a future version.|r2.7.2: Ascend/GPU/CPU => r2.8.0: Deprecated|Linear Algebraic Functions
[mindspore.ops.nsa_select_attention](https://mindspore.cn/docs/en/r2.8.0/api_python/ops/mindspore.ops.nsa_select_attention.html#mindspore.ops.nsa_select_attention)|New|Computes Native Sparse Attention algorithm for training scenarios with selective attention mechanism.|r2.8.0: Ascend|Neural Network
